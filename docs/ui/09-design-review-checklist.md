# 09-design-review-checklist.md

> Version: 1.0
>
> This document defines the UI review checklist for BK App.
>
> Every new page, feature and major UI change MUST be reviewed against this checklist before merging.
>
> The goal is consistency, not perfection.

---

# 1. Purpose

This checklist is the final verification step.

It ensures that every new screen:

- follows the design language
- reuses existing solutions
- remains consistent with the rest of BK App

This checklist should be used by

- Developers
- AI Agents
- Code Reviewers
- Designers

# 15. Questions Every Reviewer Should Ask

Can this page be simpler?

Can an existing component replace this one?

Can an existing pattern replace this one?

# BK App Design Manifest

The following principles summarize the entire design language.

## Reuse over Reinvention

Existing layouts, components and patterns are always preferred over creating new ones.

---

## Composition over Duplication

Pages are assembled from reusable building blocks.

---

## Consistency over Creativity

A predictable interface is more valuable than a unique one.

---

## Clarity over Density

Users should understand the page faster than they can admire it.

---

## Progressive Disclosure over Information Overload

Only reveal complexity when it becomes relevant.

---

## One Problem — One Solution

The same interaction should always be solved the same way.

---

## Smart Defaults over Manual Configuration

The application should make obvious decisions automatically.

---

## Navigation over Restriction

Users may explore freely.

Validation blocks actions.

Never exploration.

---

## Every Repeated Pattern Becomes a Component

If something appears twice,

it deserves a reusable component.

---

## Every Repeated Workflow Becomes a Pattern

If users repeat the same interaction,

standardize it.

---

## One Domain — One Vocabulary

One concept.

↓

One name.

↓

Everywhere.

---

## Every Screen Is Part Of One Product

No page should ever feel like it belongs to another application.

Every screen should look, behave and evolve as a natural part of BK App.
